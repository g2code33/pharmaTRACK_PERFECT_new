# Bundled PDF conversion fonts

PharmaTRACK embeds the DejaVu Sans regular and bold fonts when converting uploaded PowerPoint files to PDF. These fonts preserve lecturer slide symbols such as Greek letters, arrows, bullets, accents, and superscripts instead of replacing them with question marks.

Source: https://dejavu-fonts.github.io/
